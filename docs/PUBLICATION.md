# Publication scope

This is a clean snapshot of the existing llm-serving-benchmark-lab project, not a new implementation.
Local development commits remain in the original repository. The public history begins with this snapshot.

Per-request results and selected experiment evidence are retained unchanged. Local host/process snapshots,
assistant conversations, redundant source snapshots, virtual environments and config.local.json are omitted.
Historical manifests may reference omitted machine-only evidence; they are not assertions that all original files
are present in this snapshot. Public file hashes are listed in PUBLICATION_MANIFEST.json.

Research scripts with pinned local paths are historical experiment executors; they require explicit adaptation
and configuration before use on another machine. The root CLI accepts a configurable local config file.
No automatic diagnosis algorithm, stable trace overhead result, competition qualification or award is claimed.
Third-party frameworks remain separately installed dependencies under their own licenses.
